# 創智科研生技公司網站

這是可直接部署的靜態多頁網站，採繁體中文內容、白色與青綠色視覺，支援手機與桌機。

## 網站結構

| 網頁 | 用途 |
| --- | --- |
| `index.html` | 首頁 |
| `about.html` | 公司介紹、企業願景與使命 |
| `research.html` | 四大核心研發方向 |
| `collaboration.html` | 產學醫合作 |
| `products.html` | 預留產品專區 |
| `news.html` | 預留最新消息 |
| `contact.html` | 聯絡資訊預留與合作摘要工具 |

`dist/` 是可直接發布的網站。`build.py` 統一管理分頁內容、頁首與頁尾，`dist/styles.css` 管理版型，`dist/app.js` 管理手機選單及合作摘要功能。

## 修改與新增分頁

1. 修改 `build.py` 的 `pages` 字典以編輯分頁內容。
2. 新增分頁時，在 `pages` 新增檔名與內容；在 `nav` 新增相同檔名與顯示名稱，即可同步加入頁首及頁尾。
3. 執行 `python3 build.py` 重新產生 HTML。樣式與互動檔案不會被覆寫。
4. 執行 `python3 -m http.server 8765 --directory dist`，再於瀏覽器開啟 `http://localhost:8765` 預覽。

每個分頁具有獨立網址，可直接開啟、分享與重新整理。無需框架或套件安裝。
